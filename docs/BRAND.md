# HUK — Brand guide (v1)

Status: the raster concept board (`docs/assets/brand/huk-brand-board.jpg`) has been rebuilt as editable vector assets,
generated by `scripts/brand/` from open fonts. Confirmed by the Owner (2026-10-07): the descriptor
**FREE INTERNET RADIO** and the dark-theme colours in §3.

## 1. Name

**HUK** (Latin) / `ГУК` (Cyrillic). In Belarusian `гук` means "sound". The name is an overloaded term elsewhere
(owner decision D8). A Cyrillic lockup is **not designed yet**: the waveform-in-the-H idea has no obvious Cyrillic
counterpart and needs a design decision, not a font swap.

## 2. Logo anatomy

- **Wordmark:** three capitals in a high-contrast serif with hairline serifs.
- **The idea:** the letter **H** is gold and its crossbar is replaced by an audio waveform on a thin baseline that
  extends slightly past both stems. **UK** is grey. Gold is the sound, grey is the rest.
- **Descriptor:** `FREE INTERNET RADIO`, gold, wide-tracked caps, flanked by two thin rules.
- **Tagline:** `FEEL EVERY FREQUENCY.`, grey, small wide-tracked caps.

## 3. Colour

| Token | Value | Use | Contrast on `#1A1B1F` |
|---|---|---|---|
| Gold | `#D4AF37` | the H, descriptor, rules, icons | 8.18:1 |
| Grey (wordmark "UK") | `#7A7B80` | wordmark letters | 4.07:1 |
| Tagline grey | `#8B8C8E` | small text | 5.11:1 |
| Background | `#1A1B1F` | default surface | — |
| Background edge | `#121315` | vignette on banners | — |

The concept board's own labels disagreed with its pixels (its "charcoal `#1E1E1E`" was the background colour, and its
"UK" grey rendered at 2.78:1). The tokens above replace the board's values.

**Light theme (proposal, not yet confirmed).** Gold on white is only 2.10:1, so the light variant uses:
dark gold `#8C6D14` (4.87:1 on white), charcoal `#3B3C41` (11.0:1), tagline grey `#6B6C70` (5.24:1).

## 4. Typography

| Role | Font | Licence |
|---|---|---|
| Wordmark | Cormorant Garamond Medium (500) | SIL OFL 1.1 |
| Descriptor | Inter Medium (500), tracking 0.34 em | SIL OFL 1.1 |
| Tagline | Inter Regular (400), tracking 0.30 em | SIL OFL 1.1 |

Both families cover Latin and Cyrillic. All lettering in the SVG/PNG files is converted to outlines; no font files are
shipped. UI text should use a neutral sans; the serif is for the logotype and large display text.

## 6. Usage rules

- Clear space: at least the width of the letter H on all sides.
- Minimum size: lockup 240 px wide, wordmark 120 px. Below that use `huk-icon-small` (favicon 16 px is a silhouette
  by design: two stems and a centre bar). The ring icon starts at 64 px.
- Dark surfaces use the dark files, light surfaces the `-light` files; never put the dark wordmark on white.
- Do not recolour the H grey or UK gold, add effects, stretch, outline, or place on busy imagery.

## 7. Regenerating

```bash
npm i --no-save @fontsource/cormorant-garamond @fontsource/inter && pip install fonttools cairosvg pillow
FONTSOURCE_DIR=node_modules/@fontsource python3 scripts/brand/make_assets.py docs/assets/brand
```
Details in `scripts/brand/README.md`. Edit tokens in the scripts, rerun, commit the outputs.

## 8. Known gaps and open items

1. Cyrillic `ГУК` lockup (design decision, §1).
2. Light-theme palette awaits Owner confirmation (§3).
3. The vector set was redrawn from the concept board by script; it is not a pixel-exact copy. A human designer may refine
   the H and waveform proportions; the generator keeps that cheap to redo.
4. Provenance: if the concept board was produced with an AI image tool, check that tool's terms for brand and commercial
   use. A trademark filing also needs an original, distinctive mark (relates to D8).
