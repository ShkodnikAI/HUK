## Findings

| # | Sev | Where | Finding | Fix |

| H1 | High (before public) | `src/server/ranking/job.ts:127-134` | Anonymous `PLAYLIST`-mode start+skip sessions each produce an `EARLY_SKIP_PLAYLIST` event (−0.5, reputation 1.0, no per-actor cap, no dedupe). | H3 | Medium | `src/server/account/service.ts:166-198` | Erasure leaves rows keyed to the user: `ListenEvent.userId` (≤90 days), `VoteFlag`, `Report.reporterId` / `reporterContact`, `ArtistInvite` references, open `ListenSession`. ## Same-effect paths

Anonymous negatives (H1) and playlist adds (H2) are the same class: signals not covered by anti-fraud, which handles
`Reaction` rows only. Fix them in `signals`/`job` together; add a test per signal source.

## Residual risk

Ranking is deterministic but manipulable by a determined actor on non-reaction signals; acceptable for an invited trial,
not for a public launch (gate H-506). The cache was not load-tested against real author hosts.

P2 cleanup. H3 touches S7 — the Agent must not weaken retention.
