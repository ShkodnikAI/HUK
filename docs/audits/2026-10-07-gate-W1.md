## Findings

| # | Sev | Where | Finding | Fix |
|---|---|---|---|---|
| F1 | **High** | `src/server/env.ts` (`AUTH_URL`), `.env.example`, `docker-compose.yml` | next-auth 4.24.15 takes its base URL **only from `NEXTAUTH_URL`** (`node_modules/next-auth/utils/detect-origin.js`); the repo sets only `AUTH_URL`. Without it the magic link is built on `http://localhost:3000` (`utils/parse-url.js`): sign-in is broken in production. Enabling `AUTH_TRUST_HOST` instead would derive the origin from forwarded headers (link-poisoning risk). | H-110 |
| F2 | Medium | `src/server/auth/options.ts` `normalizeEmail`, `signin-limit.ts` | The per-email limiter key uses `trim().toLowerCase()`, Auth.js normalises with NFKC and drops everything after a comma in the domain. `victim@example.com,x` and full-width variants get separate counters but are mailed to the same address: the 5/hour per-email limit can be bypassed (mail bombing); only the 20/hour per-IP limit remains. | H-110 |
| F3 | Medium | `src/app/api/radio/now/route.ts` | The read query joins slots to tracks without `status = APPROVED AND available`. The scheduler keeps 30 minutes of future slots, so a track taken down after scheduling is still served until its slot ends (S2 defence in depth). | H-110 (query filter + test); H-206 must also delete future slots |
| F4 | Medium | `src/server/http/parse.ts` | `parseJson` reads the whole body with `req.text()` and checks the size afterwards: the limit does not bound memory. | H-110 |
| F5 | Medium | `docker-compose.yml`, `Dockerfile` | After H-103 the web image runs with `NODE_ENV=production` and needs `IP_HASH_SALT`, `CLIENT_IP_HEADER`, `EMAIL_SERVER`; compose provides none, so `docker compose up` fails at boot (S8, as designed). H-108's Docker evidence was never produced (no daemon in the Agent's sandbox). | H-111 (dev values + local mail catcher, CI smoke job) |
| F6 | Low | `src/server/http/handler.ts` | `route({ rateLimit })` takes a **static** key: it can only express one global bucket, not per-client limits. | H-110 (key as a function of the request) |
| F7 | Low | `src/server/guard.ts` | `resolveUser` ignores `bannedUntil`/`deletedAt` and can throw on a malformed cookie; it is unused. `requireRole(...roles: string[])` accepts typos (denies silently). | H-110 (remove or harden; type roles as `Role`) |
| F8 | Low | `src/server/ratelimit.ts` | `rows[0]?.count ?? 1` turns "no row returned" into a passing verdict (fail-open default arm, S9). | H-110 (throw) |
| F9 | Note | `src/server/iphash.ts` | `CLIENT_IP_HEADER` is trusted as given: IP limits can be evaded by header spoofing unless the origin is reachable only through Cloudflare. | H-504 (origin restriction) and `docs/LIMITATIONS.md` |
